# Archived games

Games pulled from the portal. The registry only discovers `src/<slug>/manifest.ts`,
so nothing here is listed, playable, typechecked or tested.

| --- | --- |

| `hanh-trinh/` | Hành Trình Anh Hùng (Hero's Journey) |

To bring one back: `git mv archived/<slug> src/<slug>`, then run `bun run gate` —
the engine may have moved on while it was here.
