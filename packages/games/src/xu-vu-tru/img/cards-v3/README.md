# Xu Vũ Trụ — cat cards v3

Original pastel cosmic cat collection art, generated with Codex built-in image generation. Every WebP is 600 × 800 pixels (3:4), encoded with cwebp quality 85. No text, titles, numerals or logos are part of the artwork.

Raw PNGs, exact prompts, contact sheet, export helper and review notes are temporarily in `_raw/` for lead review. Move `_raw/` out of the shipped asset tree after review.

All final images were visually reviewed individually and together. One Siamese draft was rejected for an extra leg and regenerated. These are standalone assets; game integration and in-game viewer validation are separate.
